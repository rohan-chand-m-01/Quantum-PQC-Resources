# Phase 1: Mathematical Foundations

This directory contains resources for the mathematical foundations of Post-Quantum Cryptography.

## Recommended Books (Digital Access)

- **Introduction to Mathematical Cryptography**
  - Authors: Hoffstein, Pipher, Silverman
  - [Access Link](https://link.springer.com/book/10.1007/978-1-4939-1711-2)

- **Linear Algebra Done Right**
  - Author: Sheldon Axler
  - [Access Link](https://linear.axler.net/)

- **A Course in Number Theory and Cryptography**
  - Author: Neal Koblitz
  - [Access Link](https://link.springer.com/book/10.1007/978-1-4419-8592-7)

## Core Topics
1. Modular arithmetic and Group Theory
2. Rings and Fields (Module Algebra)
3. Lattice Foundations: SVP and CVP
