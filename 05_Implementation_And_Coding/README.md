# Phase 5a: Implementation And Coding

Practical tools and libraries for implementing Post-Quantum Cryptography.

## Libraries

- [liboqs](https://github.com/open-quantum-safe/liboqs): C library for quantum-safe cryptographic algorithms.
- [PQClean](https://github.com/PQClean/PQClean): Clean implementations of PQC algorithms.
- [Bouncy Castle](https://github.com/bcgit/bc-java): Java implementation of NIST PQC standards.
